# Flow Overview

## User Workflow (Student)
1. **Inisialisasi**: Mahasiswa mendownload/clone template atau meng-copy ke Overleaf.
2. **Setup Identitas**: Mahasiswa mengisi file variabel seperti nama, nim, judul, dan nama dosen.
3. **Penulisan**: Mahasiswa membuka folder per-bab dan mulai menulis konten.
4. **Sitasi**: Mahasiswa menambahkan data referensi ke file `.bib` dan melakukan sitasi.
5. **Kompilasi**: Sistem mengkompilasi file `main.tex` (menggabungkan seluruh bagian dan generate list otomatis).
6. **Finalisasi**: Menghasilkan file output berupa `.pdf` yang sudah diformat sesuai standar.
