# UI/Design Specification

Dalam konteks LaTeX, spesifikasi desain merujuk pada layout tipografi, margin, dan format cetak dokumen.

## Layout Kertas
- **Ukuran**: A4 (210 mm x 297 mm)
- **Margin**:
  - Kiri (Left): 4 cm
  - Atas (Top): 3 cm
  - Kanan (Right): 3 cm
  - Bawah (Bottom): 3 cm

## Tipografi
- **Font Utama**: Times New Roman (menggunakan XeLaTeX).
- **Ukuran Font Base**: 12pt.
- **Spasi**: 1.5 Lines (Spacing).

## Format Penulisan Khusus
- **Judul Bab**: Rata tengah (Center), Bold, All Caps.
- **Sub-Bab**: Rata Kiri-Kanan (Justified), Bold.
- **Paragraf Baru**: Indentasi baris pertama (First line indent).
- **Penomoran Halaman**:
  - Bagian awal: Romawi kecil (i, ii, iii) di tengah bawah.
  - Bagian konten: Angka Arab (1, 2, 3).
