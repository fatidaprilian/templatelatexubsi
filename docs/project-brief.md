# Project Brief: Template LaTeX Tugas Akhir & Magang UBSI

## Overview
Pembuatan template LaTeX untuk Proposal, Laporan Magang, dan Laporan Tugas Akhir (Skripsi) khusus bagi mahasiswa Program Studi Teknologi Informasi di Universitas Bina Sarana Informatika (UBSI).

## Objectives
- Memastikan kesesuaian format dokumen akhir dengan buku pedoman skripsi/magang UBSI.
- Mengurangi waktu mahasiswa untuk mengurus formatting (margin, daftar isi, penomoran).
- Mendukung kolaborasi modern menggunakan Git atau Overleaf.

## Key Features
- **Pemisahan Laporan**: Opsi untuk format Laporan Magang, Proposal, dan Skripsi.
- **Auto-Formatting**: Otomatisasi Daftar Isi, Daftar Gambar, Daftar Tabel, dan Daftar Pustaka.
- **Modular Design**: Struktur file dipisah per bab agar rapi dan minim konflik jika dikerjakan bersama.

## Constraints & Assumptions
- **Assumption 1**: Universitas mengizinkan penggunaan font Times New Roman ukuran 12pt dengan spasi 1.5, margin standar Kiri 4cm, Atas 3cm, Kanan 3cm, Bawah 3cm.
- **Assumption 2**: Mahasiswa memiliki akses ke Overleaf atau instalasi TeX lokal yang mendukung XeLaTeX.
- **Next Validation Action**: Validasi ukuran margin, format cover, dan daftar pustaka dengan buku pedoman resmi UBSI yang terbaru.
