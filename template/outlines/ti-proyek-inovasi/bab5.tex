\chapter{METODE PENGEMBANGAN PERANGKAT LUNAK}


Tuliskan di sini \textbf{Pedoman Penulisan Metode Pengembangan Perangkat Lunak:} \\
Uraikan model siklus hidup pengembangan perangkat lunak (SDLC) yang dipilih untuk merealisasikan proyek inovasi ini (misalnya model Waterfall, Agile, Scrum, Spiral, RAD, atau Prototype). Jelaskan alasan rasional pemilihan model tersebut.\\
Jelaskan langkah-langkah implementasi nyata dari tahapan-tahapan model tersebut (seperti Analisa Kebutuhan, Desain Sistem/Database, Pembuatan Kode Program, Pengujian Blackbox/Whitebox, serta Pemeliharaan/Support).\\
Sebutkan bahasa pemrograman, framework, database management system (DBMS), serta alat bantu pengembangan (\textit{tools}) lain yang digunakan sepanjang pengerjaan perangkat lunak.
